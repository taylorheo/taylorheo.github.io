02 소개

빗썸 Data/AI 실, 데이터 플랫폼 팀에서 IDC와 AWS 기반 데이터 플랫폼을 설계·운영하고 있습니다. 데이터 플랫폼의 인프라 설계와 자산 관리, 보안, FinOps를 포함한 운영 업무 전반을 담당합니다.

베스핀글로벌에서는 AWS 데이터 플랫폼 구축을, 웍스피어 유한책임회사(구 잡코리아 유한책임회사)에서는 Databricks 전환과 Airflow 오퍼레이터 개발을 경험했습니다. 현재는 이 경험을 바탕으로 금융 규제와 ISMS-P 요구사항을 고려한 데이터 플랫폼 고도화와 AI Agent 도입을 진행하고 있습니다.
